# 12 · 诊断逻辑改造施工图纸

> 本文是施工图纸，不是施工记录。**审图通过后才允许动代码。**
> 上游知识依据：docs/11（核心知识主表 + 证据体系 + 缺口裁决）。
> 本轮改造只动「判定链路」，不改视觉风格、不改身体图路径数据、不接 AI、不接后端。

---

## 0. 一句话目标

把诊断从**文字驱动**（用户写感受 → 猜模式 → 推肌肉）改为**位置驱动**（用户点不适位置 → 一对一判定失衡类型 → 端出该类型完整信息）。

```
旧：坐标 → 区域 → freeText 命中模式词库 → 候选肌肉中少数着色（不写字 = 零结果）
新：坐标 → 9 个身体位置之一 → 1 个失衡类型 → 该类型完整过劳/过弱名单全显示（跨区域也显示）
```

## 2. 九个身体位置（SLOT）→ 九个失衡类型

位置是判定主键，类型与位置**一对一**。

| slotId | 用户身体语言 | 父区域（兼容） | 失衡类型 | 类型引擎 id | 书页 | 框架归类 |
|---|---|---|---|---|---|---|
| `neck` | 脖子 | neck_shoulder | 颅颈型·头前伸 | `cranio_cervical` | p235 | 上交叉 |
| `chest` | 胸口/肩前、两肩胛之间 | upper_back | 圆肩型 | `scapulothoracic` | p89 | 上交叉 |
| `shoulder_girdle` | 肩外侧/肩后深层 | upper_back | 肩卡型（盂肱） | `shoulder_glenohumeral` | p87-88 | 上交叉 |
| `mid_back` | 背部正中/上背脊柱 | upper_back | 驼背型（胸椎） | `thoracic` | p236 | 跨上/下交叉 |
| `low_back_hip` | 腰/骨盆/臀 | low_back_hip | 骨盆前倾型 | `hip` | p281 | 下交叉 |
| `thigh` | 大腿/膝 | leg | 膝型 | `knee` | p316 | 独立 |
| `calf` | 小腿/踝 | leg | 踝型 | `ankle` | p359 | 独立 |

## 3. 点击位置判定：双层保险

```
点击坐标 (svgX, svgY, view) + clickHintMuscleId
  │
  ├─ 首选：clickHintMuscleId 命中 MUSCLE_SLOT_MAP → 直接得 slotId
  │        （解决"同一坐标大区里多个类型"：点菱形肌=圆肩型，点冈下肌=肩卡型，点竖脊肌=驼背型）
  │
  └─ 兜底：点在肌肉间隙/轮廓/无类型肌肉上 → SLOT_RECTS 坐标矩形 → slotId
```

为什么必须双层：胸背一个视觉大区里塞了 3 个类型（圆肩/肩卡/驼背），它们在背面 y55-140 区间互相交错（菱形肌属圆肩、冈下肌属肩卡、竖脊肌属驼背），纯坐标矩形切不干净；而肌肉路径覆盖不到缝隙，纯肌肉 id 会点空。两层互补。

### 3.1 坐标矩形初值（SVG viewBox 200×460，施工时在模型上实测微调）

| slotId | 正面 front | 背面 back |
|---|---|---|
| `neck` | y<55 | y<55 |
| `chest` | 55≤y<110 且 55≤x≤145 | 55≤y<100 且 70≤x≤130（两肩胛之间）；100≤y<140 中带 |
| `shoulder_girdle` | 55≤y<110 且 (x<55 或 x>145) | 55≤y<100 且 (x<70 或 x>130) |
| `mid_back` | 55≤y<140 中线窄带（胸骨/肋脊） | 100≤y<140（下斜方肌区首选靠肌肉 id 走 chest） |
| `low_back_hip` | 140≤y<255 | 140≤y<255（臀区上界从 220 扩到 255，包住臀大肌/臀中肌） |
| `thigh` | 255≤y<330（x 居中躯干投影） | 同 |
| `calf` | y≥330 | y≥330 |
| `upper_arm` | (x<35 或 x>165) 且 55≤y<180 | 同 |
| `forearm` | (x<35 或 x>165) 且 y≥180 | 同 |

边界沿用现有规则：x<35/x>165 但 y<55（上斜方肌肩峰端）归 `neck`。

| slotId | 肌肉 id |

| neck | sternocleidomastoid, deep_neck_flexor, suboccipital, splenius_capitis, levator_scapulae, scalenes |
| chest | pectoralis_major, pectoralis_minor, rhomboid, trapezius_middle, serratus_anterior, trapezius_upper, trapezius_lower |
| shoulder_girdle | subscapularis, latissimus_dorsi, supraspinatus, infraspinatus, deltoid, teres_major, teres_minor |
| mid_back | erector_spinae |
| low_back_hip | iliopsoas, quadratus_lumborum, multifidus, rectus_abdominis, transversus_abdominis, obliquus_externus, obliquus_internus, gluteus_maximus, gluteus_medius, piriformis, tensor_fasciae_latae |
| thigh | quadriceps, rectus_femoris（仅数据层）, hamstrings, sartorius, hip_adductors, iliotibial_tract |

归属依据：每块肌肉取其**有 E1 书原句的类型**所在 slot（如上斜方肌 E1 仅在 p89 圆肩型减弱组 → chest，尽管它长在颈肩视觉区）；无类型肌肉按解剖位置归 slot（D9）。

## 4. 九个类型的完整数据包（第二页/第三页统一读取）

> 名单与书页严格对齐 docs/11 主表与引擎 PATTERNS 现状；本图纸只列出本轮要改的部分。
> 推断项（虚线）与主项分开存；涂色规则见第 6 节。

### ① 颅颈型 `cranio_cervical`（上交叉）
- 过劳：胸锁乳突肌、枕下肌群、肩胛提肌
- 过弱：深层颈屈肌
- 推断：头夹肌（过劳，虚线）
- 通俗表现：头不自觉往前探，脖子后面发沉发紧，看手机电脑久了更明显
- 书原文金句（卡片引用）：「过度的头部前伸姿势可能是由活动参与引起，如操作电脑的工作或经常看手机……颅颈区域前侧的肌肉会发生短缩。」

### ② 圆肩型 `scapulothoracic`（上交叉）
- 过劳：胸大肌、胸小肌
- 过弱：菱形肌、中斜方肌、前锯肌、上斜方肌、下斜方肌
- 通俗表现：含胸、两肩往前扣，肩胛骨之间发酸，打字开车看手机久了加重
- 金句：「这种肩胛胸壁位置通常与圆肩有关……需要将手放在身前的任务很多，如打字、驾驶、发短信……」

### ③ 肩卡型 `shoulder_glenohumeral`（上交叉）
- 过劳：胸大肌、背阔肌、肩胛下肌
- 过弱：三角肌、冈上肌、冈下肌、前锯肌、上斜方肌、下斜方肌
- 通俗表现：抬手、梳头、手往后背够的时候费劲或卡住

### ④ 驼背型 `thoracic`（跨框架）
- 过弱：竖脊肌（胸段）
- **治疗牵伸对象（非该模式判定的紧张组）**：胸大肌、胸小肌、髂腰肌——卡片单列「可牵伸」文字区，**图上不涂红**（证据诚实：书 p236 未把它们判为该模式紧张侧）
- 通俗表现：背挺不直、习惯性驼背，常和圆肩、头前伸一起出现

### ⑤ 骨盆前倾型 `hip`（下交叉）
- 过劳：髂腰肌、**股直肌 rectus_femoris（本轮新建）**、竖脊肌（腰段）
- 过弱：臀大肌、腘绳肌、腹直肌、腹横肌
- 推断：臀中肌（过弱，虚线）
- 通俗表现：久坐后髋前面紧、站起来要缓一下，腰容易累，屁股使不上劲
- 金句：「髋屈肌构成了骨盆前倾力偶的一半……长时间坐姿被明确列为成因。」
- 数据改动：`PATTERNS.hip.tight` 现状 `[iliopsoas, quadriceps, erector_spinae]` → 改为 `[iliopsoas, rectus_femoris, erector_spinae]`

### ⑥ 膝型 `knee`（独立）
- 过劳：腘绳肌；推断过劳：髂胫束（虚线）
- 过弱：股四头肌（语义收窄为股内侧/外侧/中间肌，不含股直肌）
- 通俗表现：膝盖发软、上下楼打软腿、大腿后侧紧
- 多角色提示：腘绳肌在本型过劳、在骨盆型过弱，卡片文案必须带「在【膝型】中」

### ⑦ 踝型 `ankle`（独立）
- 过劳：腓肠肌、比目鱼肌
- 过弱：胫骨前肌
- 通俗表现：小腿肚和跟腱紧、勾脚费劲、走路容易绊

### ⑧ 肘型 `elbow`（独立）
- 过劳：肱二头肌
- 过弱：肱三头肌
- 通俗表现：胳膊伸不直、手肘前后侧发紧

### ⑨ 腕型 `wrist`（独立）
- 过劳：前臂屈肌群
- 过弱：前臂伸肌群
- 通俗表现：手腕酸、打字握鼠标后发紧

## 6. 涂色与冲突规则

### 6.1 涂色名单（D3）

命中类型后，colored 取全部命中类型名单并集：
- main 项：实色（红=过劳 / 紫=过弱）
- inferred 项（头夹肌、髂胫束、臀中肌）：同色虚线
- `thoracic` 的牵伸对象不涂色（见 4.④）
- 名单内但当前视图没有该肌肉路径（如正面看不到背肌）：换面后正常显示，不补路径

### 6.2 同一肌肉跨类型角色冲突（多点时）

典型：腘绳肌（骨盆型=弱 / 膝型=紧）、竖脊肌（驼背型=弱 / 骨盆型=紧）、胸大肌（圆肩/肩卡=紧，无冲突）。
优先级：**该肌肉视觉位置所属 slot 的类型优先**（腘绳肌长在 thigh → 红；竖脊肌长在腰背 → 红）。
知识卡中各类型名单仍分别完整列出；涂色只取最高优先级一个色。
