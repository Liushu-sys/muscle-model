## 一、先说结论：这本书比预期好用得多

| 我原先的判断 | 拆完之后的事实 |
|---|---|
| 书里没有"过劳/过弱" | ✅ 确实没有这两个**词**——但有**一整套等价且更严谨的表述** |
| 书里可能没有"拉伸动作" | ❌ 错了。**"牵伸"出现在 64 页，"激活"出现在 68 页** |
| 只能提供肌肉起止点 | ❌ 错了。它给了**关节受限的成因 + 过劳/过弱配对 + 治疗方法** |

**关键发现**：全书有 **11 个结构完全统一的板块**，叫「**关节受限的常见模式**」。每个板块的格式是：

```
关节：XXX
关节受限的常见模式  • （什么姿势/活动受限）
可能的原因
   • XXX肌紧张            ← 这就是"过劳肌群"
   • XXX肌肌力减弱        ← 这就是"过弱肌群"
功能影响                • （不管它会怎样）
常见的治疗方法
   • 牵伸紧张肌肉          ← 这就是"拉伸"
   • 强化减弱肌肉的力量     ← 这就是"激活"
```

**你产品的第③④⑤步，全都能在这一页上找到出处。**

### 2.1 颈肩区（产品的核心）

**① 关节：颅颈区**（书页 **235**）★ 最重要

| 项 | 书中原文 |
|---|---|
| 受限模式 | 头部过度前伸姿势 |
| **过劳（紧张）** | 双侧**胸锁乳突肌**紧张、**枕下肌群**紧张、**肩胛提肌** |
| **过弱（肌力减弱/疲劳）** | **颅颈回缩肌或伸肌**肌力减弱或疲劳 |
| 功能影响 | 支撑头部和颈部的伸肌应力增加；该区域"激痛点"增加；头痛风险增加；颞下颌关节疼痛风险增加 |
| 治疗方法 | **强化**颅颈区回缩肌肌力（收下颌运动）；枕下肌群软组织松动；**牵伸**枕下肌群和胸锁乳突肌 |
| 书中注释（金句） | "过度的头部前伸姿势可能是由活动参与引起，如**操作电脑的工作或经常看手机**……颅颈区域前侧的肌肉会发生短缩，以适应其新的习惯长度。" |
| 书中补充（书页236） | "下颌运动……不仅有助于**主动拉伸紧张的枕下肌群**，还有助于拉伸颈椎底部的颈屈肌。" |

> 💬 **这段注释几乎是为你产品写的**——"看手机/电脑 → 前侧肌肉短缩"，完全可以放进 pitch。

**② 关节：肩胛胸壁关节**（书页 **89**）

| 项 | 书中原文 |
|---|---|

## 五、一个必须知道的细节：同一块肌肉可以"又紧又弱"

书里明确出现了这种情况，**这是你产品逻辑需要处理的**：

| 肌肉 | 在哪个模式里是"紧" | 在哪个模式里是"弱" |
|---|---|---|
| **腘绳肌** | 膝关节模式（膝屈肌紧张 → 牵伸） | 髋关节模式（髋后伸肌力减弱 → 强化） |
| **菱形肌** | 盂肱模式（肩胛骨下旋肌紧张 → 牵伸） | 肩胛胸壁模式（肩胛骨后缩肌力减弱 → 强化） |
| **竖脊肌** | 髋/腰骨盆模式（腰背部伸肌紧张 → 牵伸） | 胸椎模式（竖脊肌区域性肌力减弱 → 强化） |

**所以不能用"一块肌肉 = 固定倾向"的死表。** 正确逻辑是：

```
第1步  AI 先判断：用户说的是哪个「关节受限模式」？
第2步  再按该模式的配对表，给出紧张组（过劳）和肌力减弱组（过弱）
第3步  倾向仅作兜底：模式判断不出来时，才用默认倾向
```

**在 prompt 里加这句话就能解决：**

```
判断顺序：先匹配「关节受限的常见模式」（颈肩走颅颈区/肩胛胸壁，腰走髋关节/胸椎，
膝走膝关节，踝走踝关节，腕走腕关节），再按该模式确定紧张肌群与肌力减弱肌群。
注意同一块肌肉在不同模式下角色可能相反（如腘绳肌：膝模式=紧张，髋模式=弱）。
只有在模式无法确定时，才使用肌肉的默认倾向。
```

## 六、"体感 → 关节模式"映射表（给 AI 的第 0 步）

用户说的话不可能带解剖词，所以要有一层映射：

| 用户可能说 | → 关节模式 | → 过劳 | → 过弱 |
|---|---|---|---|
| 脖子酸、后脑勺沉、转头费劲、头疼 | **颅颈区** | 胸锁乳突肌、枕下肌群、肩胛提肌 | 深层颈屈肌 |
| 肩膀沉、耸着肩、肩膀僵 | **肩胛胸壁** | 胸大肌、胸小肌 | 菱形肌、斜方肌中束、中/下斜方肌、前锯肌 |
| 圆肩、含胸、驼背、挺不直 | **肩胛胸壁 + 胸椎** | 胸大肌、胸小肌 | 竖脊肌（胸段）、菱形肌、中/下斜方肌 |

2. 再按该模式给出：紧张肌群（=过劳）、肌力减弱肌群（=过弱）

② func   —— 只写它负责什么动作，2–3 个，动词开头
