## 二、做全身：要改的不只是数量，有一处会动到核心逻辑

### 2.1 三个连带变化

| # | 变化 | 工作量 |
|---|---|---|
| 1 | 肌肉库 10 块 → **34 块** | 小，AI 生成 |
| 2 | 人体图从「颈肩局部」→ **全身正面 + 全身背面**，34 块都要标 x/y | **中，这是今天最大的一块活** |
| 3 | ⚠️ **"过劳 / 过弱"这个模型，不是全身通用的** | **要提前想清楚，否则明天会卡住** |

### 2.2 第 3 条必须展开讲 —— 这是真问题

「过劳肌群 + 过弱肌群」这套配对，教科书里**明确写死的只有两处**：

- **上交叉**（颈肩）：上斜方肌/肩胛提肌/胸肌 过劳 ↔ 深层颈屈肌/菱形肌/下斜方肌 过弱
- **下交叉**（腰骨盆）：髂腰肌/竖脊肌 过劳 ↔ 臀大肌/臀中肌/腹肌 过弱

**膝盖、脚踝、手肘、手腕——没有这种经典配对。**

所以如果用户说"膝盖前面疼"，你给不出"过弱肌群"，双栏就会空一半，产品显得不完整。

### 2.3 解法：用一条可以泛化的通则

肌动学里有一条**通用规律**（《基础肌动学》第 3 章骨骼肌、以及各章的肌肉功能表里都有体现）：

> **跨两个关节的肌肉 → 容易变短变紧（倾向"过劳"）**
> **只跨一个关节的深层稳定肌 → 容易被抑制变弱（倾向"过弱"）**

拿这条去套全身就说得通了：

| 部位 | 跨双关节 → 过劳 | 单关节稳定肌 → 过弱 |
|---|---|---|
| 颈肩 | 上斜方肌、肩胛提肌、胸大肌/小肌 | 深层颈屈肌、菱形肌、下斜方肌、前锯肌 |
| 腰骨盆 | 髂腰肌、竖脊肌（腰段）、阔筋膜张肌 | 腹横肌、臀大肌、臀中肌 |
| 大腿膝 | 腘绳肌（跨髋+膝）、股直肌（跨髋+膝） | 股内侧肌（单关节）、臀中肌 |
| 小腿踝 | 腓肠肌（跨膝+踝） | 胫骨前肌、比目鱼肌（单关节） |
| 上肢 | 胸大肌、背阔肌、前臂屈肌群 | 冈下肌/小圆肌、斜方肌中下束 |

**这样一来全身都能给双栏，而且每一条都有书里的机制可依，不是我编的。**

### 2.4 落地规则：给 AI 加一句话

在 system prompt 里补一条：

```
优先使用"跨双关节→过劳 / 单关节稳定肌→过弱"这个规律判断。
颈肩（上交叉）和腰骨盆（下交叉）有明确教科书配对，直接套用。
其他部位按上面的规律推断，不允许凭空发明配对关系。
```

### 2.5 但我要给你一个诚实的建议

**全身版本，5 小时做不完。**

34 块 × 2 张图的坐标标定，光目视微调就要 40–60 分钟。而且 34 块意味着 AI 编造的空间变大。

**我的建议**（你自己定）：

| 方案 | 做法 | 适合 |
|---|---|---|
| **A. 全身覆盖，颈肩做深** ⭐ 推荐 | 34 块全建，但 **Demo 只演示颈肩 + 腰两条链**（这两条最完整、最讲得清），其他部位点了也能出结果，只是一句带过 | 既撑得住"全身"的说法，又保证演示质量 |
| B. 纯全身 | 34 块全做，每块都同等深度 | 你时间真的够 |
| C. 只颈肩 | 维持 10 块 | 你已经否了 |

## 六、生成出来的 `muscles.ts` 长这样

```ts
export type MuscleType = 'tight' | 'weak'
export type Side = 'front' | 'back'
export type Region =
  | 'neck_shoulder' | 'upper_back' | 'low_back_hip' | 'leg' | 'arm'

export interface Muscle {
  id: string
  name: string
  alias: string[]
  region: Region
  type: MuscleType
  side: Side
  x: number   // 0-100 百分比
  y: number   // 0-100 百分比
  desc: string
  senses: string[]
}

export const MUSCLES: Muscle[] = [
  {
    id: 'trapezius_upper',
    name: '上斜方肌',
    alias: ['斜方肌上束', '斜方肌'],
    region: 'neck_shoulder',
    type: 'tight',
    side: 'back',
    x: 50, y: 18,
    desc: '脖子两侧到肩膀的那一大片，一紧张就往上耸',
    senses: ['脖子酸', '脖子两侧发紧', '耸肩', '转头受限', '肩膀僵硬'],
  },
  // …其余 27 块
]
```

**⚠️ 一条硬规矩（不要省）**：前端拿到 AI 结果后，**必须**用 `MUSCLES` 里的 id 做交集过滤——AI 返回了库里没有的 id，直接丢掉。34 块的时候这条比 10 块时更重要。

## 七、防编造：三道校验

| 校验 | 做法 | 为什么 |
|---|---|---|
| id 交集过滤 | 前端过滤掉库外 id | AI 最爱发明肌肉名 |
| 数量上限 | 一次最多返回 tight 3 块 + weak 3 块 | 返回 8 块一定是瞎猜 |
| region 一致性 | 如果返回的肌肉跨了 3 个以上 region，判定为乱答，改为只保留置信度最高的那一组 | 全身版新增的坑 |

第三条是全身版才有的：10 块时代全在颈肩，不存在这个问题。
