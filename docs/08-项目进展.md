## 2026-10-05 · 可交互原型日

### 三页原型闭环跑通（`assets/body_preview.html`）

**做了什么**：单页预览升级为完整三页原型，全部在纯 HTML/JS 单文件内完成（引擎经
`mm-engine.js` 动态加载）——

1. **选择页**：肌肉图撑满屏幕，点选/取消多选，正反面切换（选中状态跨面保留），
   左上「已选 X 处」计数（按肌肉名称计，左右同名只算一处），底部描述输入框 +
   圆形确认按钮（无选中时禁用）
2. **诊断结果页**：过劳=橘、过弱=紫着色；推断项虚线描边区分；点肌肉弹 iOS 风
   Sheet（名称 / 是什么 / 当前问题 / 建议方向）；顶部标题可展开诊断摘要卡
3. **缓解动作页**：三个场景（工位·户外 / 健身房 / 床上）各推荐 3 个动作，
   按诊断结果精准匹配（过劳配放松拉伸、过弱配激活强化）

**验证**：浏览器自动化实测全绿，控制台零报错。

### 缩放与点选手感

- 右下角 +/− 按钮（0.5x 步进，最大 4x）、1x 复位、按住拖动平移、Ctrl+双指缩放
- **修复关键 bug**：`pointerdown` 里无条件 `setPointerCapture` 导致真实点击被
  滚动容器截胡、肌肉收不到事件——改为只有开始拖动/捏合时才 capture
- 网格虚线 `<line>` 加 `pointer-events:none`，不再拦截点击

### 诊断全覆盖：47 组肌肉零遗漏

- 9 条本地模式直接覆盖约 30 组；其余 17 组（腹内斜肌、胫骨前肌、臀中肌等）
  走**肌肉级兜底**：反查模式分组 → 查不到按 `muscles.ts` 的常识倾向 `type` 推断
- 兜底项图上有虚线 + 「推断」标签，摘要注明推断数量，不冒充确诊
- 「当前问题」重写为因果链（过劳：缩短绷紧→血流差→酸胀发紧；过弱：该发的力
  发不出→邻肌代偿→代偿的累、自己用进废退），每块肌肉代入自己的功能描述
- 「建议方向」从动作库按肌肉+状态匹配具体动作名（状态无匹配时放宽到该肌肉
  全部动作），用户拿到的是可执行的动作而非泛泛建议

### 工程与协作基建

- **备份双保险**：`body_preview_original.html`（最初预览版）冻结存档，
  Git 标签 `body-preview-original` 指向原始提交 `a95d4bf`

- 文档：README 补「项目现状」与文件分工约定；新增 `07-团队协作操作手册.md`
  （小白向 Git 分支/PR 流程）；新增本文档

**还没做**：AI 引擎接入（引擎预留 `ai` 分支）；用户确认页（引擎支持否决制，
