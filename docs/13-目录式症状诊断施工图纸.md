# 13 · 目录式症状诊断施工图纸（v1，2026-10-08 批准）

> 替代 docs/12 的"位置驱动"路线。核心变化：**用户不再点身体位置让引擎猜问题，而是点四大区域 → 从症状目录里自己选问题 → 每个症状确定性对应一套紧/弱肌群**。
> 引擎从"判定器"退化为"查表器"，坐标兜底/slot 冲突/paintAs 多类型仲裁等不确定性代码全部退役。

## 0. 产品决策（已拍板）

- D1 全身分四大区域：**肩颈 / 肩臂 / 腰背 / 臀腿**
- D2 第一页：保留人体图，整图覆盖 4 个半透明热区，点热区弹出该区域**症状目录抽屉**；症状支持多选；选完点"查看身体状态"
- D3 症状目录用通俗文案（"久坐腰硬邦邦，刚起身直不起来"），进入第二页后用专业名解释（病名/表现/肌肉学解释/紧弱名单/涂色）
- D4 症状总数 **14**（9 个书内模式 + 5 个久坐高频补充），候选 15（髂胫束）本期不做
- D5 **感受卡（feel/freeText）彻底删除**——目录选择本身就是感受表达
- D6 **第三页与肌肉解耦**：每个症状直接挂动作包（坐姿缓解 1 + 站姿加强 1 + 长期建议），不再按肌肉 id 匹配动作
- D7 多症状可叠加涂色；唯一互斥组：**症状3（上交叉综合征）与症状1、2 互斥**（3 是 1+2 的复合套餐，且上斜方肌在 1/2 与 3 中角色冲突）。UI 上选 3 时 1/2 置灰并提示"①②都有就选我"
- D8 红旗不触发分析（无文字输入源），但在症状 5（手腕）、8（腰）、14（梨状肌）的解释卡底部保留静态就医提示文案
- D9 视觉风格不变；记录/收藏/我的页面不动；不接 AI/后端

## 1. 交互流程

```
第一页（诊断）
  人体图四大热区（半透明覆盖层 + 区域名）
    └─ 点热区 → 底部抽屉列出该区域症状（通俗文案 + 一句补充描述）
         └─ 勾选症状（可跨区多选；互斥组处理见 D7）
              └─ 已选症状以小 chip 显示在图下方，可点 × 移除
                   └─「查看身体状态」
第二页（结果，视觉沿用现页）
  人体模型按所有选中症状的并集涂色（红=偏紧 / 紫=偏弱 / 虚线=资料推断）
  Bottom Sheet = 按选中顺序排列的症状解释卡（每卡：专业名/表现/肌肉学解释/双栏名单/书引或文献/免责声明/红旗提示）
  点图上肌肉 → 知识卡（内容沿用阶段3：在【症状名】中偏紧/偏弱、推断标注、多裂肌腰方肌中性文案规则作废——它们现在在症状8/9里有正式角色）
第三页（建议）
  每个选中症状一个板块：
    坐姿缓解动作（工位可做）×1
    站姿加强动作 ×1
    长期建议：姿势/行为/环境 各 1–2 条
  跟练节奏 UI、剂量、示意图全部沿用现有 actionScreenHtml
```

### 多症状涂色合并规则

1. 同名肌肉跨条目去重；同 state 直接并集
2. 冲突（同肌既 tight 又 weak）：按用户选择顺序，**先选的症状为准**，后选条目里的冲突肌肉不涂色但仍出现在该症状卡名单（卡片只解释本症状，不代表全局涂色）
3. 主项与推断项冲突时主项优先
4. paintAs 不变：rectus_femoris 复用 quadriceps 色块（症状10/11 股直肌紧红；症状12 股四头肌弱紫——单点 10/11 或 12 各自正常；若用户同时选 10+12，按规则2先选为准）
5. stretchOnly（症状7）永不涂色，只在卡片里列文字

### 新增 7 个动作（写进 ACTIONS，howto/dose/why 编辑后补全）

1. `sit_pec_er_stretch` 坐姿肩前侧牵伸：坐稳，手背后伸或手肘外开，胸肩前侧有拉伸；20–30秒×2
2. `sit_thoracic_ext` 坐姿抱头胸椎伸展：双手抱头，吸气胸椎向后上挺、肘外展，呼气回；10次×2
3. `stand_glute_kick` 站姿扶椅后踢腿：扶稳椅背，一腿缓慢向后伸、臀夹紧2秒；12次×2/侧
4. `stand_abd_leg` 站姿侧抬腿：扶椅背，一腿向侧方抬、骨盆不歪；12次×2/侧
5. `sit_ql_sidebend` 坐姿侧向伸展：坐稳双腿踩实，一手过头向对侧侧屈，腰侧拉开感；20–30秒×2/侧
6. `sit_calf_towel` 坐姿毛巾拉小腿：坐地一腿伸直，毛巾绕前脚掌向身体拉、膝尽量伸直；20–30秒×2/侧
7. （备选，若施工时发现肘症状坐姿加强太空则加）`sit_chair_dip` 椅子撑体：双手撑椅面，屈肘身体下沉再撑起激活肱三头肌；8–10次×2

### 长期建议（ADVICE_POOL 扩充）

现有池只有颈肩/腰背/上肢条目，本期新增下肢/通用条目，并改为**按症状 id 直连**（去掉 regions 模糊匹配）：

- 新增 posture：久坐每30–45分钟起身2分钟（通用）；坐姿双脚平放不跷二郎腿（8/9/14）；屏幕与视线平齐避免前探（1/3）
- 新增 behavior：每天10分钟臀桥/蚌式唤醒臀部（10/11）；久坐后先慢走再弯腰（8）；握鼠标手臂有支撑、手腕不压桌边（5）
- 新增 environment：腰后放腰靠保持腰椎自然曲度（8/10）；椅子高度让大腿与地面平行、膝略低于髋（10/11/13）；桌下留够伸腿空间（13）

每症状最终挂 3–6 条（三类各 1–2），具体在数据层落。
